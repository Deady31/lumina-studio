# Lumina Studio

Éditeur web tout-en-un de **Web Design, Shaders WebGL2, Lumières Atmosphériques, Animations de Texte et Composants UI Premium** — 100 % Vanilla (HTML5, CSS3, JS, WebGL2 / Canvas 2D), zéro dépendance runtime.

## Fonctionnalités
- **8 moteurs de fonds animés** (WebGL2 Mesh Gradient, Aurora Borealis, God Rays, Liquid Blobs, Grille interactive Dots/Squares/Perspective/Truchet, Particules & Constellations, Starfield 3D, Bayer Dither / Halftone / Matrice ASCII live).
- **Lumières & Atmosphère** empilables (Hero Spotlights, Ambient Orbs, Cursor Spotlight, Lens Glow, Film Grain 35mm, Vignette).
- **Typographie & Text FX** (Split-Text Reveal, Shimmer métallique, Liquid Gradient, Scramble/Decode, Glitch RGB, Kinetic Marquee, Texte circulaire rotatif).
- **Composants UI Premium** (Apple Liquid Glass avec réfraction SVG, Carte 3D Tilt + Foil Holographique, Carte Bento Spotlight + Border Beam, Boutons Magnétique/Beam/Shimmer/Ripple, Dock macOS interactif, Pill lumineux).
- **Curseur & Micro-FX** (Custom Lerp Cursor, Traînée Particules/Ruban, Spotlight Mask, Click Sparks) + **Motion Lab** (Spring Physics temps réel).
- **Export de Code Pro** (HTML/CSS/JS autonome, React + Tailwind CSS, CSS Tokens) + JSON, PNG & Clip WebM.
